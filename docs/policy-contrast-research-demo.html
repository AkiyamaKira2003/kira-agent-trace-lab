What this demonstration establishes

The offline evaluator can compare two declared policies on the same previously recorded case without contacting a model or replaying an action. It cannot infer the real human's intention from the action log alone.

The backing case and candidate policy are self-authored research fixtures. Their expected label is not an independently authenticated grant. The privacy-safe summary intentionally omits recipients, case IDs, tool names and arguments.

Local, standalone HTML/CSS. No scripts, external fonts, hosted assets, analytics, APIs or network requests. This is a static illustration of a recorded policy comparison, not an interactive runtime agent or a published benchmark.
